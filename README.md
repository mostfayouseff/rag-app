# Rag-App
Application that implement Rag concept

## Requierment
- python 3.8 or later

#### install python3 with miniconda

1) download and install minicoda from [here](https://www.anaconda.com/docs/getting-started/miniconda/main).

2) create a new env from miniconda check this for more info [here](https://docs.conda.io/projects/conda/en/latest/user-guide/tasks/manage-environments.html):

```bash
cona create -n env-name 
```

3) conda env activate
```bash 
conda activate env-name
```
